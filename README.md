# ココロノセイセイ — ポートフォリオ

ココロノセイセイ一作品のためのサイトです。ビルド不要の静的サイトで、`main` にプッシュすると GitHub Pages へ自動デプロイされます。

## 動画の置き場所

ページ内の動画は「スロット」になっています。`assets/videos/web/` に、スロットと同じ名前の mp4（あれば同名の jpg がポスター）を置くだけで表示されます。

| スロット | 場所 |
| --- | --- |
| `intro` | 作品概要の全幅映像 |
| `flow-01` 〜 `flow-06` | 体験の流れ（6段階） |
| `g2` | 粒子の章の全幅映像 |
| `g1` `g3` `g4` `g5` `g6` `g7` | 体験の記録 |
| `gallery-08` `gallery-09` | 空きスロット（体験の記録の末尾） |

- 枠の形は、`index.html` の各 `<figure class="film" style="--ratio:16/9">` の `--ratio` で変えられます（`21/9`、`4/3`、`1/1`、`9/16` など）。
- 元の撮影データ（`assets/videos/MVI_*.MP4`）は数GBあるので Git では無視しています（`.gitignore`）。Webに載せるものは、短く切って軽くした mp4（1本あたり10MB以下が目安）を `assets/videos/web/` に置いてください。GitHub は1ファイル100MBまでです。
